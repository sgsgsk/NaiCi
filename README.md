# 背诵单词

本地 Windows 单词背诵小工具：录入词库、对照背诵、中英默写。

## 运行（开发）

```bat
pip install -r requirements.txt
python main.py
```

## 打包

```bat
build_exe.bat
```

完成后在 `发布\背诵单词.exe`，词库目录为同级 `发布\记录文件\`。

也可双击 `启动.bat`。

## 另一台电脑使用注意

1. 请解压到**桌面或文档**等普通文件夹，不要放进 `C:\Program Files`。
2. 若从网盘/压缩包下载后被 Windows 拦截：右键 exe → 属性 → 勾选「解除锁定」→ 确定。
3. **不需要**以管理员身份运行；程序会在可写目录保存词库。
4. 请携带整个 `发布` 文件夹（至少包含 `背诵单词.exe` 与 `记录文件`）。

## 功能概览

- **背诵单词**：上英下中，上一个 / 下一个
- **背诵英文 / 背诵中文**：输入默写，记录错误次数
- **录入单词**：纯文本自动区分中英，完成后命名保存为 md
